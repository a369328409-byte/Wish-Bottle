# 我的心愿瓶 · Wish Bottle

> a little jar for today's wishes

一个单文件的轻量级「攒钱 + 打卡 + 日记」小应用。完成任务赚取金币，攒够心愿金额就把它「拿下」，还可以每天写一篇随笔。

## 功能特性

### 数据看板
- **Saved**：当前已攒金额
- **Wishes**：心愿清单数量
- **Done**：累计完成任务数
- **Spent**：已用于实现心愿的金额

### 心愿清单
- 许愿：填写心愿名称、所需金额、备注（可选）
- 每个心愿显示攒钱进度条与百分比
- 攒够后可一键「🎉 拿下」：扣除存款、计入已花、移入已实现列表
- 已实现心愿支持「撤回」（退回金额）与折叠收纳
- 心愿可随时删除

### 日记本（按天）
- 日期导航：前后翻页查看任意一天，一键回到「今天」
- **今日任务**：
  - 🔄 循环任务：添加后每天自动出现
  - 🧩 单次任务：只在当天出现
  - 完成任务获得奖励金额，取消完成自动扣回
  - 快捷输入：任务名后写 `+数字` 自动识别奖励金额，如 `自己做饭 +20`（默认奖励 10）
- **今日随笔**：每天可保存一段文字

## 数据存储

所有数据保存在浏览器 `localStorage`，不依赖任何后端服务：

| 键名 | 内容 |
| --- | --- |
| `oc_goals` | 心愿清单 |
| `oc_achieved` | 已实现心愿 |
| `oc_cyclic` | 循环任务定义 |
| `oc_daily` | 按天的任务记录与随笔 |
| `oc_saved` | 已攒金额 |
| `oc_spent` | 已花金额 |

> 注意：数据仅存在于当前浏览器中。清除浏览器数据、更换设备或浏览器后数据不会同步，请谨慎清理。

## 使用方式

无需构建、无需安装依赖，直接用浏览器打开 `index.html` 即可：

```bash
# 本地预览（可选）
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

也支持添加到手机主屏幕（已配置 apple-mobile-web-app 相关 meta），作为独立网页应用使用。

## 技术栈

- 纯原生 HTML / CSS / JavaScript，单文件实现
- 字体：Google Fonts（Cormorant Garamond + Noto Serif SC），数字优先使用本地宋体
- 图标：Font Awesome CDN
- 持久化：localStorage
