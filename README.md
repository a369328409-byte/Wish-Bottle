# Wish Bottle

> a little jar for today's wishes

一个单文件的轻量级「攒钱 + 打卡 + 日记」小应用。完成任务赚取金币，攒够心愿金额就把它「拿下」，还可以每天写一篇随笔。

## 功能特性

### 数据看板
- **Saved**：当前已攒金额
- **Wishes**：心愿清单数量
- **Done**：累计完成任务数
- **Spent**：已用于实现心愿的金额

### 心愿清单
- 点击标题行右侧 **＋** 弹出弹窗许愿：填写心愿名称、所需金额、备注（可选）
- 每个心愿显示攒钱进度条与百分比
- 攒够后可一键「🎉 拿下」：扣除存款、计入已花、移入已实现列表
- 已实现心愿支持「撤回」（退回金额）与折叠收纳
- 心愿可随时删除

### 日记本（按天）
- 日期导航：前后翻页查看任意一天，一键回到「今天」
- **今日任务**：
  - 点击标题行右侧 **＋** 弹出小弹窗录入任务
  - 弹窗字段：任务名称、奖励金币（默认 10）、任务分组、任务类型（分段选择）
  - 任务类型共五种：
    - **单次**：只在创建当天出现，完成后不再出现
    - **每日**：每天自动出现
    - **每周**：每周只在创建当天的星期几出现（如周一）
    - **每月**：每月只在创建当天的日期出现（如每月 1 号）
    - **自定义**：仅在设定的起止日期范围内出现，可填起始 / 截止日期
  - 同一循环任务在不同日期的完成状态相互独立，各天打卡互不影响
  - 完成任务获得奖励金额，取消完成自动扣回
  - 任务分组（一体化下拉）：
    - 弹窗内分组选择器 + 列表内分组标题行「折叠 / 展开」
    - 新建分组：底部输入行，带 ✓ / ✕ 确认 / 取消按钮
    - 管理分组：重命名（行内编辑）、排序（HTML5 原生拖拽）、删除
    - 删除分组弹独立确认弹窗：可选「移至未分组」或「一并删除」
    - 分组颜色、顺序、折叠状态全部持久化到 localStorage
- **今日随笔**：
  - 每天可保存一段文字
  - textarea 输入框随内容自动调整高度（上限 120px）
  - 点击标题行可折叠 / 展开，折叠后只剩标题一行贴日记本底部
  - 随笔区高度自适应，折叠 / 展开均不影响任务列表高度

### 专注模式（全屏计时层）
- **入口**：点击日记本里任意「未完成」的任务行，全屏进入专注层（已完成任务不可进入）
- **三种计时模式**（顶部切换，默认番茄钟）：
  - **正计时**：不设上限，只累计已用时间，进度环按每分钟走一圈
  - **倒计时**：跑满设定时长自动停下
  - **番茄钟**：一轮专注跑满后停下，可选择「开始休息 / 跳过休息 / 完成」；休息倒计时结束自动回到下一轮专注
- **时长选择**：点击时钟弹出滚轮（自定义分钟数 + 常用时长档位），待机态随时重选
- **常用时长设置**：右下角「设置」面板分「专注时长 / 休息时长」两组，可增删档位（休息组仅番茄钟模式出现）
- **时钟样式**：右下角「样式」在**圆环**（进度环 + 秒针圆点）与**卡片翻页**（四张翻页数字卡）之间切换，样式偏好跨会话记忆
- **秒针音效**：计时中每秒一次「擦擦」走动声（Web Audio 本地合成 tick / tock 交替，无外部音频文件）；右下角「声音」一键开关，重开时自动试听一声，偏好持久化
- **番茄轮次与星星**：星星数 = 已完成番茄轮次，顶部提示「第 N 轮专注」；星星单行封顶 10 颗，更多时显示 `× N` 计数
- **休息态**：进度环与圆点变柔绿 + 顶部「休息中」提示，与专注阶段一眼区分
- **专注时长回写任务**：只累计专注阶段（休息不计入），每跑满一轮番茄即时写入任务记录，专注层还开着就能看到外部列表数值同步刷新
- **位置一致性**：三种模式下时钟（圆环 / 翻页卡片）均水平居中且垂直位置完全一致，切换模式不会跳动
- **安全防护**：计时进行中锁定模式切换并提示；已累计时长时切换模式会二次确认；点关闭 / 完成时弹窗可选「已完成」（结算金币）或「放弃」（丢弃本次计时）

### 皮肤切换
- 六套配色皮肤：薰衣草紫（默认）、鎏金岁月、蜜桃轻粉、晴空浅蓝、薄荷生巧、星夜呢喃（深夜模式）
- 页面底部彩色圆点切换栏，圆点颜色对应各皮肤主色
- 皮肤偏好通过 localStorage 记忆，下次打开自动应用

### 响应式布局
- **移动端（<900px）**：单列纵向排列，与桌面端共用同一套卡片和弹窗样式
- **桌面端（≥900px）**：双列等高布局
  - 左列：数据看板 + 心愿清单；右列：日记本（跨两行）
  - 整体居中，两栏等宽，中间留 20px 间隔
  - 整体高度被视口限制（`calc(100vh - 40px)`），不随内容无限撑长
  - 任务列表和心愿清单固定高度（自适应视口），超出内容各自滚动
  - 左右栏底部严格对齐，窗口高矮自适应，最小可保证各显示 1-2 条

## 数据存储

所有数据保存在浏览器 `localStorage`，不依赖任何后端服务：

| 键名 | 内容 |
| --- | --- |
| `oc_goals` | 心愿清单 |
| `oc_achieved` | 已实现心愿 |
| `oc_cyclic` | 循环任务定义 |
| `oc_daily` | 按天的任务记录与随笔 |
| `oc_saved` | 已攒金额 |
| `oc_spent` | 已花金额 |
| `oc_theme` | 当前皮肤名称 |
| `oc_groups` | 任务分组列表（`[{id, name, color}]`） |
| `oc_collapsed` | 分组折叠状态（`{groupId: true}`） |
| `oc_noteCollapsed` | 今日随笔是否默认折叠 |
| `oc_focusPresets` | 常用专注时长档位（分钟数组） |
| `oc_breakPresets` | 常用休息时长档位（分钟数组） |
| `oc_focusCfg` | 各模式 / 休息上次使用的时长（`{countdown, pomodoro, break}`，毫秒） |
| `oc_tickSound` | 秒针音效开关（`on` / `off`，缺省为开） |

> 注意：数据仅存在于当前浏览器中。清除浏览器数据、更换设备或浏览器后数据不会同步，请谨慎清理。

## 使用方式

无需构建、无需安装依赖，直接用浏览器打开 `index.html` 即可：

```bash
# 本地预览（可选）
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

也支持添加到手机主屏幕（已配置 apple-mobile-web-app 相关 meta），作为独立网页应用使用。

## 技术栈

- 纯原生 HTML / CSS / JavaScript，单文件实现
- 字体：Google Fonts（Cormorant Garamond + Noto Serif SC），数字优先使用本地宋体
- 图标：Font Awesome CDN + 主题色内联 SVG 描边图标
- 音效：Web Audio API 本地合成（秒针 tick / tock，无音频文件依赖）
- 持久化：localStorage
- 布局：CSS Grid（桌面端双列）+ Flexbox（卡片内部自适应滚动）
